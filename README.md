# Portal informativo do Banco do Nordeste (BNB)

Site independente, em português, sobre o **Banco do Nordeste do Brasil S.A.**: FNE, Crediamigo, Agroamigo, Pronaf, conta corrente e canais digitais (**BNB Login / Nordeste Eletrônico**).

**Produção:** [https://nel.bnbguia.mom/](https://nel.bnbguia.mom/)

> Aviso: portal **informativo**. Não é o Banco do Nordeste, não autentica cliente e **não coleta senha**. Login real só em [bnb.gov.br](https://www.bnb.gov.br/) / [nel.bnb.gov.br](https://nel.bnb.gov.br/) ou apps oficiais.
